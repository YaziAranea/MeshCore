# Откуда взяты городские пресеты

Источник — публичный каталог [MeshCoreTel](https://meshcoretel.ru/ru/OMS).
Помощник содержит автономный снимок: интернет при подключении ноды не нужен.
Дата получения указана в интерфейсе. Это не дата последнего изменения каждого
города: такой информации API источника не предоставляет.

## Что переносится

Частота, полоса, SF и CR. Частота округляется до 1 кГц, как отображение сайта
с тремя знаками после запятой в МГц. Например, `868.731018` → `868.731` МГц.
Исходные строки сохранены в `sourceRadio` для проверки преобразования.

API источника не отдаёт число голосов, дату изменения и размер хеша маршрута.
Поля `votes`, `sourceUpdatedAt`, `pathHashBytes` поэтому равны `null`, а не нулю.
При применении пресета помощник сохраняет текущий размер хеша маршрута ноды.
Мощность передачи, FEM и ретрансляция не входят в городской пресет.

Параметры на сайте определяются сообществом и могут меняться. Выбор города
не меняет ноду автоматически: сначала показ параметров, затем подтверждение.
Используйте подходящий диапазон платы/антенны и разрешённые в вашем месте
параметры передачи. Само наличие пресета не подтверждает разрешение на частоту.

## Почему не скопирована одна страница

На момент подготовки обычный HTML по адресу `/ru/OMS` содержал начальный
регион `MOW`. Поэтому парсить видимый серверный текст как настройки Омска нельзя.
Также `/api/regions/all` и режим `all_regions=true` возвращают больше регионов,
чем доступно в селекторе, причём для части используются значения по умолчанию.

Снимок собирается так:

1. Из `/api/regions/catalog` берётся только список `regions` страны с кодом
   `RU`, только записи `kind=iata` и `country_code=RU`. Географическая группировка
   соответствует источнику, а не отдельной классификации SmartUI.
2. Из `/api/regions/radio-settings?all_regions=true` выбираются только точные
   совпадения `code` с этим списком. Прочие записи не добавляются.
3. Проверяются все четыре поля и поддерживаемые диапазоны SX1262. Отсутствующие
   и неподдерживаемые настройки исключаются; их коды и причины остаются
   в `metadata.excluded`. Настройки другого города никогда не подставляются.
4. Русские подписи берутся из строкового словаря сайта. Код сайта не исполняется.
   Для неизвестной подписи сохраняется имя/код из каталога; название не угадывается.
5. В снимок записываются время получения UTC, адреса и SHA-256 ответов источника.

Это снимок опубликованного каталога. Не аппаратная проверка, не подтверждение
местным администратором и не гарантия, что радиообстановка не изменилась.
Сам API может опубликовать стандартные значения. Одинаковая частота у разных
городов не считается ошибкой и не заменяется догадками.

## Обновление для разработчика релиза

Из корня репозитория, Node.js 20+:

```text
node tools/update_meshcoretel_presets.js --refresh
node --test tools/usb-helper/test_presets.js
git diff -- tools/usb-helper/presets.js
```

Команда делает только чтение публичных адресов MeshCoreTel и обновляет блок данных
в `presets.js`. Остальной код, нода и GitHub не меняются. При ошибке источника
прежний снимок остаётся на месте. Ответы ограничены по размеру/времени;
редиректы и выполнение загруженного JavaScript запрещены.

Перед выпуском сравните несколько городов с источником, проверьте список
исключений и повторно упакуйте помощник. В готовом HTML нет сетевой загрузки
каталога: обновления приходят с новой версией помощника.
