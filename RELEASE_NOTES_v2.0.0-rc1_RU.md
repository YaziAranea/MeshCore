# MeshCore Smart UI nRF52 v2.0.0-rc1

Предварительный порт русскоязычного Smart UI на MeshCore `PowerSaving-v17`, закреплённый на `a3b9ad91a5bf04e7e00713595469dc868de53628`. В область RC входят только три companion BLE-платы на nRF52840.

Стабильный PS16 `v1.0.0` остаётся эталоном. `v2.0.0-rc1` — major-миграция: аппаратные испытания этого порта пока не заявляются.

## Файлы

| Плата | Файл |
|---|---|
| Heltec T096 FEM ON | `T096_FEM_SmartUI_v2.0.0-rc1.uf2` |
| Heltec T114 с TFT | `T114_SmartUI_v2.0.0-rc1.uf2` |
| ProMicro nRF52840 + Heltec RA62 | `ProMicro_RA62_SmartUI_v2.0.0-rc1.uf2` |

Также скачайте `SHA256SUMS.txt` и проверьте файл до прошивки. Не прошивайте ProMicro-файл в FakeTec/HT-RA62.

## Главное

- Компактные часы, сеть, чат, непрочитанные ЛС, анонс и настройки без пустых страниц.
- Экранная клавиатура и адресная отправка в чат или companion-контакту.
- Ретрансляторы отфильтрованы из контактов.
- Непрочитанные показывают отправителей личных сообщений, количество и последнюю реплику, а не историю каналов.
- Одна общая мелодия важных уведомлений; строго два проигрывания.
- Ночной запрос тишины в 23:30 до 07:30.
- Выбор мелодии, шрифта и темы полноценными списками.
- Аппаратный GPS на T096/T114 с понятным `GPS ON/OFF`; на ProMicro GPS отсутствует.
- Wake-fix ProMicro по пользовательской кнопке D6/GPIO6.

## Шрифты и экраны

- T096: TFT 160×80, 15 публичных bitmap-профилей и 7 тем.
- T114: ST7789 240×135, 10 профилей и 7 тем.
- ProMicro RA62: SSD1306 OLED 128×64, стили `Classic`, `Air`, `Strong`, `Narrow`, `Dense`.

Галерея и QA-матрицы: `docs/SCREENS_RU.md`.

## Прошивка

1. Сверьте модель платы и имя UF2.
2. Проверьте SHA-256.
3. Подключите антенну и USB-кабель с данными.
4. Быстро дважды нажмите физический Reset.
5. Скопируйте UF2 на появившийся диск загрузчика.
6. После запуска проверьте региональные радиопараметры.

Подробно: `docs/FLASHING_RU.md`.

## BLE PIN

Используйте шестизначный код, показанный нодой. Для этих дисплейных целей compile-time `BLE_PIN_CODE=123456` при отсутствии сохранённого PIN служит sentinel для генерации случайного активного кода, а не обязательно является постоянным рабочим PIN.

## Проверки

Проверка релизных файлов:

- PlatformIO build: `3 / 3 SUCCESS`;
- static release contract: `31 PASS / 0 FAIL`;
- exact framebuffer QA: `455 PASS / 0 FAIL`;
- UF2 structure validation: `3 PASS / 0 FAIL`.

Размеры flash: T096 77,8%, T114 78,0%, ProMicro 93,2%. Подробные RAM/flash, размеры файлов и SHA-256 находятся в `BINARY_VALIDATION.txt` и `SHA256SUMS.txt`.

Симуляция T096 использовала реальные bitmap glyphs, T114 — фактическое масштабирование 128×64 → 240×135, ProMicro — реальные OLED 5×7-таблицы.

## Ограничения

- Страница версии показывает имя платы и `SmartUI 2.0.0-rc1`.
- Физическая проверка файлов `v2.0.0-rc1` не заявляется. Сборка, статический аудит и точная симуляция не заменяют испытание конкретного экземпляра.
- Phone GPS отключён и не работает без отдельного приложения/сервиса на телефоне.
- T096 FEM требует особого внимания к антенне, питанию, температуре, фактической мощности и местному законодательству.
- Импорт/экспорт приватного ключа доступен через companion-протокол; храните ключ как секрет.
