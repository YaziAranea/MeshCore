# SmartUI V4

> **ЭКСПЕРИМЕНТАЛЬНЫЙ UI.** Обычный публичный выпуск для шести плат,
> не скрытый черновик. Latest означает текущий выпуск, а не доказанную
> стабильность на всех физических платах. SmartUI V3 сохранён для отката.
> Аппаратная проверка этих исправлений не заявляется.

## Что исправлено относительно SmartUI V3

- **Напоминания без телефона на nRF52840:** T096, T114 и ProMicro снова
  повторяют звуковую серию непрочитанного важного ЛС/упоминания через
  **две минуты от начала предыдущей серии**. Ранее настройка `once=1`
  полностью отключала такие звуковые напоминания; это не смена пяти минут на две.
  Bluetooth-соединение для этого не требуется. Прочтение/сброс важного
  уведомления прекращает напоминание; тишина и выбранный режим учитываются.
- **Ровно два проигрывания за серию на nRF52840:** короткий `burst-gap`
  больше не запускает лишнюю серию. Повторный callback не перезапускает
  уже активную серию; новые важные события во время неё объединяются,
  а не запускают каждое свою немедленную серию. Это исправление найденного
  программного пути, не универсальная гарантия против любых внешних событий.
  Прежняя LED-серия ProMicro сохранена; число проигрываний остальных
  плат этим исправлением не меняется.
- **GPIO зуммера:** недопустимый сохранённый вывод больше не мешает
  использовать штатный допустимый вывод платы. На платах без зуммера
  вывод не выдуман.
- **LED и звук на одном GPIO:** управление LED/PWM больше не перехватывает
  вывод во время звуковой мелодии. Исправление покрывает программный
  конфликт; фактическая распайка и исправность зуммера требуют проверки.
- **Настройки не сбрасываются.** Сохранённые мелодия, резонанс, GPIO,
  режимы, калибровка, контакты и identity не заменяются новыми defaults.
  Важные уведомления по умолчанию могут оставаться в режиме «Свет».
  Если нужен звук ЛС/упоминания, выберите **«Зумер» или «Оба»**
  в настройках важных уведомлений; «Свет» и «Выкл» звука не дают.

Причина конкретного случая молчащего ProMicro без проверки распайки/платы
не подтверждена. Выпуск устраняет найденные дефекты программного пути,
а не обещает исправность каждого физического экземпляра.

## Что сохранено

- UI V3: mute-иконка без «ТИХО», меню, пиктограммы, все шрифты и темы.
- Клавиатура, адресная отправка с подтверждением, companion-контакты,
  непрочитанные ЛС, избранное и безопасная калибровка/отмена.
- Одна общая мелодия; без профилей, BLE export/import и черновиков.
- BLE PIN, синхронизация времени, ADC и защита АКБ 3,2/2,7 В.
- Радиопараметры, FEM/LNA и энергосбережение; это не исправление
  и не подтверждение обсуждавшегося энергопотребления ESP32.
- Одна Wireless Paper FULL: без леса, с клавиатурой и автоматическими часами.
- V3 FS2: прежняя узко ограниченная инициализация известного пустого образа
  и двухэтапное подтверждение сброса. V4.3/Paper не получили FS2.
- Заставка теперь показывает `MeshCore` и короткое `V4`. Уникальный
  идентификатор платы остаётся внутри прошивки для валидатора.

## Какой файл скачать

`V4` в имени — номер SmartUI, не ограничение совместимости Heltec V4.

| Плата | Файл |
|---|---|
| T096 FEM ON | `T096_UI_V4.uf2` |
| T114 с TFT | `T114_UI_V4.uf2` |
| ProMicro nRF52840 + RA62 | `ProMicro_RA62_UI_V4.uf2` |

UF2 копируется на загрузочный USB-диск соответствующей nRF52840-платы.

| ESP32-S3 | Чистая установка | Обновление работающей ноды |
|---|---|---|
| Heltec V3 OLED | `Heltec_V3_UI_V4-merged.bin` | `Heltec_V3_UI_V4-update.bin` |
| Heltec V4.3 OLED FEM ON | `Heltec_V4.3_UI_V4-merged.bin` | `Heltec_V4.3_UI_V4-update.bin` |
| Wireless Paper FULL | `Paper_UI_V4-merged.bin` | `Paper_UI_V4-update.bin` |

- **Обычное обновление ESP32: `-update.bin`, адрес `0x10000`, без Erase.**
  В файле только приложение; он не перезаписывает файловую систему.
- **Чистая установка: `-merged.bin`, адрес `0x0`.** Это не обычное обновление.
  Для web flasher имя должно заканчиваться точно на `-merged.bin`:
  суффикс браузера ` (1)` перед `.bin` может привести к неправильному адресу.

**До прошивки безопасно сохраните ключ ноды, контакты и настройки.
Не публикуйте резервную копию. Erase Flash удаляет данные.**
Исправление уведомлений не сбрасывает настройки, но разрушительная
чистая установка всё равно удаляет их.

### Heltec V3: merged стирает данные даже без Erase

`Heltec_V3_UI_V4-merged.bin` содержит подготовленную пустую SPIFFS и
перезаписывает identity/контакты/настройки **даже без Erase Flash**.
Применяйте только для намеренной чистой установки. Для работающей ноды —
update без очистки.

Update не содержит FS. Прежний FS2 может подготовить хранилище при
точном совпадении SHA256 известного пустого образа и правильной разметке.
Произвольное повреждение, FF-раздел и ошибка чтения не разрешают
молчаливое форматирование; другой сброс требует двух подтверждений.
Предыдущий запуск FS2 после ручного сброса подтверждён пользователем;
это не аппаратная проверка V4.

### V4.3/Paper: ограничение чистой установки не исправлено

Механизм хранилища не менялся. Их merged **не содержит подготовленной
SPIFFS**: полностью очищенная установка может дать `STORAGE ERROR`.
Работающую ноду обновляйте update **без Erase**. V3 BIN не подходит
другой плате. Новый номер UI не исправляет это ограничение.

## Проверки и границы

Публикация разрешена только после зелёного CI: шесть целевых сборок,
три UF2 и три BIN-пары, V3 FS2/подготовленная SPIFFS, native-тесты,
совместимость общих компонентов и актуальные UI-проверки.

В CI добавлены `test_important_notify_v4.py` и `test_notify_pins_v4.py`:
проверяются напоминания, ограничение nRF-серии и конфликт GPIO.
Локально прошли 120 сценариев настоящего C++ (31 мелодия на трёх
nRF-платах плюс BLE/тишина/прочтение/переполнение таймера) и 6262 случая GPIO.
Результат программной проверки не заменяет прослушивание зуммера на плате.

- T096: реальные bitmap-шрифты, xAdvance и видимые границы букв.
- T114: масштаб 128×64 → 240×135, Y+1, реальная тема и высота глифов.
- OLED: встроенные глифы пяти профилей, не подмена крупным 5×7.
- Paper: framebuffer 250×122 и реальные E213-шрифты.
- Mute и заставка: настоящие C++-фрагменты, геометрия и сохранение маркеров.

Меню не менялось; в галерее честно сохранены симуляции V3, заставка
пересоздана для V4. Симуляция не доказывает радиодоставку, ток, яркость,
физическую кнопку, ghosting и время BUSY e-paper. Фото платы важнее макета.

Выпуск содержит **14 assets**: девять прошивок, `SHA256SUMS.txt` для UF2,
`SHA256SUMS-ESP32.txt` для BIN, `RELEASE-MANIFEST.json`, эти примечания
и `SmartUI_V4_all-boards.zip`. Манифест связывает прошивки с одним точным
исходным commit, размерами и SHA-256. Повтор публикации использует ту же
страницу тега `smartui-v4`, не создаёт дублирующие релизы.
