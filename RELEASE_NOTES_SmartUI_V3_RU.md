# SmartUI V3

> **ЭКСПЕРИМЕНТАЛЬНЫЙ UI.** Обычный публичный выпуск для шести плат,
> не замена стабильной версии и не скрытый черновик. Предыдущая beta.2
> остаётся Latest и доступна для отката. Аппаратная проверка новой версии
> на всех шести платах не заявляется.

## Что изменилось относительно experimental.2

- На главном экране тихий режим показывает **только mute-иконку**.
  Слово «ТИХО» больше не рисуется, независимо от шрифта и свободного места.
  Перечёркнутый динамик имеет отдельный растр для каждого размера.
  Отключённые сигналы в меню теперь обозначены «Выкл», а не «Тихо».
- На заставке — `MeshCore` и короткая версия `V3`, без названия города
  и длинного идентификатора платы. Уникальный board marker сохранён
  внутри прошивки для проверки правильного файла, но на заставке не выводится.
- Имя выпуска, девять файлов прошивок и общий ZIP стали короткими.
  `V3` здесь — номер SmartUI, не ограничение совместимости платой Heltec V3.

## Что сохранено

- Остальной UI experimental.2: обновлённые пиктограммы, все шрифты и темы,
  подсказки удержания и привычные разделы меню.
- Избранное, безопасная калибровка/отмена, клавиатура, адресная отправка
  с подтверждением, только companion-контакты и непрочитанные ЛС.
- Одна общая мелодия; без профилей, BLE export/import и черновиков.
- Аптайм под часами, отображение напряжения, защита АКБ 3,2/2,7 В.
- Постоянный BLE PIN, ручная страница сопряжения, синхронизация времени.
- Радиопараметры, FEM/LNA и энергосбережение. Это не исправление
  и не подтверждение обсуждавшегося энергопотребления ESP32.
- Одна Wireless Paper FULL: без леса, с клавиатурой и автоматическими часами.
- V3 FS2 с узко ограниченной инициализацией известного пустого образа
  и двухэтапным пользовательским подтверждением сброса.
  Пользователь подтвердил запуск предыдущей FS2 после ручного сброса;
  это не аппаратная проверка новой сборки.

## Какой файл скачать

| Плата | Файл |
|---|---|
| T096 FEM ON | `T096_UI_V3.uf2` |
| T114 с TFT | `T114_UI_V3.uf2` |
| ProMicro nRF52840 + RA62 | `ProMicro_RA62_UI_V3.uf2` |

UF2 копируется на загрузочный USB-диск соответствующей nRF52840-платы.

| ESP32-S3 | Чистая установка | Обновление работающей ноды |
|---|---|---|
| Heltec V3 OLED | `Heltec_V3_UI_V3-merged.bin` | `Heltec_V3_UI_V3-update.bin` |
| Heltec V4.3 OLED FEM ON | `Heltec_V4.3_UI_V3-merged.bin` | `Heltec_V4.3_UI_V3-update.bin` |
| Wireless Paper FULL | `Paper_UI_V3-merged.bin` | `Paper_UI_V3-update.bin` |

- **Обычное обновление: `-update.bin`, адрес `0x10000`, без Erase.**
  Файл содержит только приложение и не перезаписывает файловую систему.
- **Чистая установка: `-merged.bin`, адрес `0x0`.** Это не обычное обновление.
  Для веб-флешера имя должно заканчиваться точно на `-merged.bin`:
  браузерный суффикс ` (1)` перед `.bin` может привести к неправильному адресу.

**Сохраните ключ ноды, контакты и настройки безопасным способом до эксперимента.
Не публикуйте резервную копию. Erase Flash удаляет данные.**

### V3: merged стирает данные даже без Erase

`Heltec_V3_UI_V3-merged.bin` содержит подготовленную пустую SPIFFS и
перезаписывает identity/контакты/настройки **даже без Erase Flash**.
Применяйте его только для намеренной чистой установки.
Для сохранения работающей ноды используйте update без очистки.

Update не содержит FS. В runtime FS2 сохранены прежняя проверка полного SHA256
точно известного пустого образа и отдельно подтверждаемый сброс данных.
Произвольное повреждение, стёртый FF-раздел и ошибка чтения не разрешают
молчаливое автоматическое форматирование.

### V4.3/Paper: ограничение чистой установки не исправлено

Их механизм хранилища не менялся. Эти merged **не содержат подготовленной
SPIFFS**: полностью очищенная установка может закончиться `STORAGE ERROR`.
Работающую ноду обновляйте update **без Erase**. Не используйте V3 BIN
на другой плате и не считайте новый UI исправлением их чистой установки.

## Проверки и границы

Публикация разрешена только после зелёного CI: шесть целевых сборок,
три UF2 и три BIN-пары, V3 FS2/подготовленная SPIFFS, native-тесты,
совместимость общих компонентов и актуальные UI-проверки.

- T096: настоящие bitmap-шрифты, xAdvance и видимые границы букв.
- T114: масштаб 128×64 → 240×135, Y+1, настоящая двухцветная тема.
- OLED: встроенные глифы пяти профилей и границы полного статуса.
- Paper: framebuffer 250×122 и реальные E213-шрифты.
- Mute: production C++ проверяется на полную иконку и отсутствие текстовой ветви.

Симуляции не доказывают радиодоставку, ток, яркость, физическое управление,
ghosting или время BUSY e-paper. При расхождении фото платы важнее макета.

Выпуск содержит **14 файлов**: девять прошивок, `SHA256SUMS.txt` для трёх UF2,
`SHA256SUMS-ESP32.txt` для шести BIN, `RELEASE-MANIFEST.json`, эти примечания
и `SmartUI_V3_all-boards.zip`. Манифест связывает каждую прошивку с одним
точным исходным commit, размером и SHA-256. Старые теги и assets не заменяются.
