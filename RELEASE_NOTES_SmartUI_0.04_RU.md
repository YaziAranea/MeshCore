# SmartUI 0.04

Новая нумерация по просьбе автора: **0.04**, не V4 и не V0.04.
Продолжение SmartUI V5 для тех же шести плат. Старый V5 остаётся для отката.

## Изменения после аудита

[Соответствие замечаний аудита исправлениям и тестам](https://github.com/YaziAranea/MeshCore/blob/smartui-0.04/docs/AUDIT_FIXES_0.04_RU.md).

- Очередь сообщений удаляет запись только после принятия полного кадра интерфейсом BLE. При занятом интерфейсе запись остаётся доступной для повторного запроса.
- Напоминания различают поколения сообщений: получение нового ЛС не наследует подавление предыдущего. Отправители с одинаковыми именами различаются по ключу.
- Калибровка ADC до подтверждения влияет только на предварительный показ, а не на защитную отсечку АКБ. Неудачное сохранение не должно показываться как успешное.
- Перед ручным выключением/перезагрузкой проверяется сохранение отложенных изменений. При ошибке ручное действие прерывается с сообщением; аварийное выключение по низкому напряжению не задерживается бесконечно.
- Ночное предложение не стирает набранное сообщение и не прерывает редактирование настроек. Коррекция времени назад не выдаётся за наступление утра.
- Входящее окно на Paper получает свой срок показа, а не закрывается сразу старым таймером бездействия.
- Таймеры ESP32 BLE учитывают переполнение `millis()` после длительной работы. Ожидание будущего отложенного сохранения контактов не держит основной цикл непрерывно активным.
- Paper ограничивает ожидание BUSY и повторяет неудачную отрисовку; общая линия питания радио не выключается для восстановления экрана.
- V4.3 и Paper, как V3, получают подготовленный пустой SPIFFS в **merged**. Чистая установка больше не рассчитывает на остатки старого хранилища. Если такой образ не монтируется, подготовка памяти разрешена автоматически только после полного совпадения с известным пустым образом; чужие данные и повреждённый раздел без подтверждения не форматируются.
- Аварийное ожидание при ошибке хранилища обслуживает планировщик и контроль батареи; неудачный сброс данных не возвращает ноду в обычную работу с частично стёртым состоянием.
- Выключатель штатных LED, тишина, одна общая мелодия, два проигрывания в серии и двухминутное напоминание сохранены.

## Новое: внешний GPS на ProMicro

Тот же UF2 поддерживает обычные UART/NMEA-приёмники с сигналами 3,3 В.
GPS по умолчанию выключен, без подключённого модуля прошивка работает как раньше.

- GPS TX → ProMicro **P0.20 / D3**.
- GPS RX → **P0.22 / D4**, необязательно.
- GND общий. Питание — по документации GPS-платы, **не от GPIO**.
- Скорость NMEA определяется автоматически; «нет данных UART» отличается от поиска спутников.
- Без внешнего ключа выключение GPS в меню останавливает UART, но не отключает физическое питание приёмника.

[Полная инструкция подключения](https://github.com/YaziAranea/MeshCore/blob/smartui-0.04/docs/PROMICRO_GPS_RU.md).

Всё вместе: `SmartUI_0.04_all-boards.zip`. В выпуске также есть SHA256 и `RELEASE-MANIFEST.json` с исходным коммитом.

**Работающая ESP32-нода: `update.bin`, адрес `0x10000`, без Erase Flash.**
**Чистая установка: `merged.bin`, адрес `0x0`. Merged содержит пустое хранилище и стирает identity, контакты и настройки даже без отдельного Erase.**
Сначала сохраните нужные данные в приложении. Не используйте merged как обычное обновление с сохранением данных.

## Честные границы

- Передача кадра в BLE-очередь — не подтверждение доставки приложению и не прочтение человеком. Протокол приложения не менялся.
- Исправление ожидания сохранения устраняет конкретную лишнюю активность CPU, но не доказывает время работы от аккумулятора. Для сравнения потребления нужны одинаковые условия и замер тока.
- GPS работает с NMEA GGA/RMC. UBX-only и нестандартные скорости требуют настройки самого модуля.
- Хост-тесты, сборки и точная проверка геометрии не заменяют испытания дисплея, GPS, LED и радиоканала на физической плате.
- Защита АКБ по умолчанию 3,2 В, при выключении — нижний порог 2,7 В. Раннее восстановление без доступных настроек использует безопасный порог сборки 3,2 В. Программная отсечка не заменяет аппаратную защиту аккумулятора.
