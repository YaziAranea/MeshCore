# Поддерживаемые платы

Стабильный `v2.0.0-rc1` поддерживает три nRF52-цели. Текущий публичный hotfix `v2.1.0-dev.1` из ветки `smartui-ps17.2-dev` добавляет Heltec V4.3 OLED, Heltec Wireless Paper и общую ручную страницу BLE PIN. Он заменяет `v2.1.0-dev`. Совпадение процессора само по себе недостаточно: должны совпадать дисплей, радиомодуль, распайка кнопки и управляющие линии.

## Сводная таблица

| Плата | Environment | MCU | Дисплей | GPS | FEM/LNA | Формат |
|---|---|---|---|---|---|---|
| Heltec T096 FEM ON | `Heltec_t096_companion_radio_ble_femon` | nRF52840 | TFT 160×80 | да | да | UF2 |
| Heltec T114 | `Heltec_t114_companion_radio_ble` | nRF52840 | ST7789 240×135 | да | нет | UF2 |
| ProMicro RA62 | `ProMicro_ra62_companion_radio_ble` | nRF52840 | SSD1306 128×64 | нет | нет | UF2 |
| Heltec V4.3 OLED | `heltec_v4_3_companion_radio_ble_femon_smartui` | ESP32-S3 | SSD1306 128×64 | да | да | merged/update BIN |
| Wireless Paper WOOD | `Heltec_Wireless_Paper_companion_radio_ble_smartui_wood` | ESP32-S3 | e-paper 250×122 | нет | нет | merged/update BIN |
| Wireless Paper FULL | `Heltec_Wireless_Paper_companion_radio_ble_smartui_full` | ESP32-S3 | e-paper 250×122 | нет | нет | merged/update BIN |

На всех пяти платах страница `Дополнительно → Калибр. АКБ` меняет реальный коэффициент ADC. Значение сохраняется только после подтверждения. Калибровка требует мультиметра: multiplier исправляет масштаб, но не аппаратный offset.

На всех пяти платах `v2.1.0-dev.1` случайный активный BLE PIN открывается одним переходом вперёд с часов, сохраняется между обычными перезагрузками и скрывается после подключения.

## Heltec T096 FEM ON

- Экран: 160×80, драйвер семейства ST7735.
- UI использует встроенные bitmap-шрифты; обычная 5×7-симуляция для этой платы неверна.
- Внешний усилительный тракт управляется прошивкой.
- По умолчанию `LORA_TX_POWER=9`: комментарий аппаратного профиля оценивает это примерно как 22 dBm после усилителя.
- `MAX_LORA_TX_POWER=22` относится к настройке выхода SX1262, а не к гарантированно измеренной мощности на разъёме антенны. При внешнем FEM фактический EIRP может быть существенно выше.
- RX gain FEM включён.
- В целевой сборке есть аппаратный GPS.
- Цель собирается с `-Os`: это сохраняет extra-FS и все 15 публичных шрифтов. Размер flash: RC — 77,8%, hotfix `2.1.0-dev.1` — 77,9% области приложения.

Нельзя прошивать T096-файлом другую T96-подобную плату без сверки распайки и FEM. Не включайте передачу без согласованной антенны.

## Heltec T114 с дисплеем

- Требуется версия платы с цветным дисплеем.
- Физическая матрица: 240×135.
- Драйвер строит интерфейс в логических координатах 128×64 и масштабирует его с коэффициентами `1.875 × 2.109375`, `Y_OFFSET=1`. Именно эта особенность учитывается в точной симуляции.
- В целевой сборке есть аппаратный GPS.
- Настроенная мощность SX1262 по умолчанию — 22 dBm.
- Цель собирается с `-Os`; это уже прописано в `variants/heltec_t114/platformio.ini`.
- Размер flash: RC — 78,0%, hotfix `2.1.0-dev.1` — 78,4% области приложения.

Файл не предназначен для `Heltec_t114_without_display_*`.

## ProMicro nRF52840 + Heltec RA62

Поддерживается конкретная схема:

- плата ProMicro/SuperMini на nRF52840;
- радиомодуль Heltec RA62 на SX1262;
- SSD1306 OLED 128×64 по I²C;
- пользовательская кнопка UI на D6/GPIO6.

В документации D6 означает не кнопку Reset и не встроенную кнопку любой случайной ProMicro. Это физическая пользовательская кнопка, электрически соединённая с выводом D6 целевого проекта. Она листает экраны и будит дисплей.

GPS в environment `ProMicro_ra62_companion_radio_ble` исключён через `-UENV_INCLUDE_GPS`. Если к своей ProMicro вы отдельно подключили GPS, этот релиз всё равно не активирует его.

Размер flash: RC — 93,2%, hotfix `2.1.0-dev.1` — 93,4% области приложения (666040 / 712704 байт, запас 46664 байт). ProMicro остаётся самой тесной из трёх nRF52-целей; после изменений обязательно контролируйте отчёт линковщика.

## Heltec V4.3 OLED FEM ON

- Поддерживается именно OLED 128×64, не V4 TFT.
- Аппаратный GPS включён; состояния GPS и значок тишины разведены с группой АКБ в реальной OLED-геометрии.
- LNA/FEM включён через `RADIO_FEM_RXGAIN=1`.
- Физический зуммер не заявлен; `PIN_MSG_TONE` намеренно отсутствует.
- ESP32-S3 требует BIN, а не UF2: merged для чистой установки/Web Flasher и update для обновления приложения.
- Hotfix `2.1.0-dev.1` занимает 22,9% области приложения (1503193 / 6553600 байт).

## Heltec Wireless Paper

- Физическая матрица: 250×122, 1-bit e-paper.
- `WOOD` — рекомендуемый профиль без экранной клавиатуры. Остальные часы/чат/ЛС/настройки доступны.
- `FULL` добавляет клавиатуру и target picker. Каждое движение курсора обновляет e-paper; полный refresh выполняется периодически против ghosting.
- GPIO45/VEXT питает одновременно дисплей и LoRa-тракт. Поэтому `AUTO_OFF_MILLIS=0`; обычное OLED-выключение дисплея способно обесточить радио.
- GPIO0 — пользовательская кнопка, GPIO18 — TX LED. Их нельзя выдавать за tone pin.
- Аппаратного GPS, FEM, вибромотора и зуммера в профиле нет; невозможные меню скрыты.
- Заявлены ревизии с поддерживаемым определением BUSY polarity; Wireless Paper V1.0 не заявлен.
- PIN-страница открывается вручную и не заменяет часы/лесной screensaver в idle-режиме; после связи она скрывается.
- Hotfix `2.1.0-dev.1` занимает 38,8% области приложения в WOOD (1296761 / 3342336 байт) и 38,9% в FULL (1301789 / 3342336 байт).

## Что не поддерживается

- FakeTec/HT-RA62 и environment `ProMicro_faketac_htra62_companion_radio_ble`.
- Heltec V4 TFT, обычный Heltec V3 и другие ESP32-S3-платы вне двух новых точных профилей.
- T114 без дисплея.
- T096 FEM OFF.
- Любая ProMicro с другой распайкой OLED, кнопки или RA62.
- Репитерные, room server, USB-only и sensor environments.

Исходный MeshCore содержит много других вариантов, но наличие их конфигураций в дереве не превращает их в часть этого публичного релиза.

## Как убедиться, что файл выбран правильно

Перед прошивкой сравните сразу три вещи:

1. Полное название платы и установленного радиомодуля.
2. Environment и формат файла: UF2 нельзя путать с merged/update BIN.
3. SHA-256 из манифеста того же Release/CI-артефакта: `SHA256SUMS.txt` для UF2 или `SHA256SUMS-ESP32.txt` для development BIN.

Если остаётся сомнение между ProMicro RA62 и FakeTec либо между V4 OLED и TFT, не прошивайте наугад: это разные цели с разными аппаратными нюансами.
