Текущий публичный выпуск — [Smart UI 0.08](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.08). Это новая сборка: её встроенная версия также **0.08**, версия USB-помощника — **1.3**. Описанное ниже переименование без пересборки относится только к прежним выпускам 0.01–0.06.

## Что изменилось

1. Названия страниц выпусков, файлов прошивок и общих архивов приведены к одной последовательности.
2. Имена внутри архивов, списки SHA-256 и манифесты согласованы с новыми файлами.
3. Существующие Git-теги и ссылки на страницы выпусков сохранены. Старый технический тег в адресе страницы — не ошибка; он по-прежнему указывает на исходный код той же сборки.
4. Прямые ссылки на переименованные файлы изменились. Если старая ссылка на скачивание не работает, откройте сохранённую страницу выпуска и выберите файл в разделе **Assets**.

## Что не изменилось

1. Готовые BIN/UF2 не пересобирались и не изменялись побайтно. Их контрольные суммы остались прежними. Контрольные суммы архивов и изменённых документов пересчитаны.
2. На заставке, в меню «О прошивке» и USB-консоли старые сборки продолжают показывать прежнюю встроенную версию. Например, файл выпуска **0.06** сообщает **0.06-test.2**. Это одна и та же прошивка, а не ошибочный файл.
3. Переименование не добавляет исправлений и не подтверждает аппаратную стабильность. Выпуски 0.05 и 0.06 сохраняют экспериментальный характер прежних тестовых сборок. Ограничения и предупреждения их описаний остаются в силе.
4. **USB Helper 1.0 / 1.1 / 1.2** — отдельная версия утилиты, не номер прошивки. Файлы помощника сохранены без изменений; в его интерфейсе и документации могут встречаться прежние номера прошивок.
5. Исходные файлы документации и названия веток могут содержать прежние номера. Для сопоставления используйте таблицу выше; история исходного кода не переписана.

## Проверка файла

Скачивайте прошивку и `RELEASE-MANIFEST.json` из **одного выпуска**. Поле `release_version` в обновлённом манифесте хранит номер публикации; `version` — реальную встроенную версию. Поля `commit` и `source_commit` сохраняют исходный commit сборки.

USB Helper 1.2 проверяет переименованные файлы выпусков 0.04–0.06 по их манифестам. У более старых сборок нет необходимой встроенной метки исходного кода; переименование не добавляет её и не снимает это ограничение проверки.

**Для работающей ESP32-ноды выбирайте `update.bin` и совместимую схему обновления без очистки. `merged.bin` предназначен для чистой установки; он может заменить identity, контакты и настройки даже без Erase. Переименование не меняет способ прошивки.**
