# Smart UI 0.20 — MeshCore 1.18 и управление без экрана

SmartUI обновлён до официальной базы **MeshCore 1.18.0**. Сохранены привычное меню,
CLI, настройки звука, ADC, энергосбережение и исправления 0.19, включая белую
полоску снизу T114 и доступ к BLE PIN.

## Что нового

- Официальное ядро 1.18.0 объединено с SmartUI. Сохранены безопасная запись
  настроек и проверки занятости радио; подробности — в [описании переноса](docs/MIGRATION_1.18_RU.md).
- **ProMicro / FakeTec V4 с HT-RA62 без дисплея:** отдельный готовый UF2.
  Экран не инициализируется; настройки, уведомления и защита аккумулятора работают.
- **USB Helper 2.7:** состояние ноды и управление доступны без экранного меню.
  Настройки дисплея скрываются по возможностям прошивки. Успех записи показывается
  после подтверждения и чтения результата с ноды.
- **BLE PIN можно прочитать через USB.** Кнопка Helper запрашивает действующий
  код, не меняя его и не переключая подключение. В локальном CLI: `get pin`.

## BLE без экрана: какой PIN вводить

| Ситуация | Как подключиться |
|---|---|
| ProMicro / FakeTec Headless 0.20 без прежних настроек | Выберите ноду в совместимом MeshCore-приложении на телефоне. Когда появится запрос PIN, введите **`123456`**. Компьютер для этого не нужен. |
| Обновление ранее настроенной ноды, в том числе переход с OLED на headless | Используйте **прежний сохранённый PIN**. Обновление не заменяет его на `123456`. |
| PIN неизвестен | Прочитайте действующий код через USB Helper по инструкции ниже. Предварительное BLE-сопряжение не требуется. |
| Плата с работающим дисплеем | С часов перейдите на один экран вперёд, на страницу `ПИНКОД BLE`, и введите показанные цифры. |

Обычная перезагрузка PIN не меняет. В экранном профиле при запуске драйвера дисплея и
отсутствии сохранённого кода создаётся и сохраняется случайный PIN; `123456`
не является общим паролем всех плат. **Не используйте Erase или сброс настроек
только ради неизвестного PIN.**

### Как прочитать неизвестный PIN через USB

1. Скачайте `SmartUI_USB_Helper_2.7.html` из этого выпуска и откройте его в
   Chrome или Edge **на компьютере**. Подключите ноду USB-кабелем с передачей данных;
   закройте флешер и другие программы, занимающие этот порт.
2. Если нода работает в Bluetooth или Wi-Fi, выберите в Helper **«Настройки
   (консоль)»**. Если ранее включён USB-компаньон — **«Настройки
   (USB-компаньон)»**. На новой headless-ноде стандартный режим — Bluetooth.
3. Нажмите **«Выбрать USB-порт»**, дождитесь подключения, затем во вкладке
   **«Подключение»** нажмите **«Показать PIN»**.
4. Введите шесть показанных цифр при запросе на телефоне. Через 30 секунд Helper
   скрывает код только на своём экране: PIN ноды остаётся прежним.

Чтение PIN не включает Bluetooth и не меняет способ подключения. Если нода
осталась в USB-компаньоне или Wi-Fi, во вкладке «Подключение» отдельно выберите
**Bluetooth** и подтвердите переключение. Текущее соединение может закрыться;
после переподключения проверьте выбранный режим.

## Как обновиться и подключиться

1. Скачайте файл своей платы и проверьте SHA-256 из этого же выпуска.
2. На nRF52 скопируйте UF2 на диск загрузчика, **без `FLASH_ERASE`**.
3. На работающей ESP32 установите **`update.bin` по `0x10000` без Erase**.
   Для чистой установки предусмотрен `merged.bin` по `0x0`: он заменяет identity,
   контакты и настройки даже без отдельного Erase.
4. Подключитесь по BLE с кодом по инструкции выше. Для настройки через компьютер
   откройте Helper 2.7 и выберите подходящий USB-режим; прочитайте состояние ноды.
5. Проверьте имя ноды, радиопараметры и показание аккумулятора. ADC калибруйте по
   мультиметру: коэффициент зависит от конкретного делителя и платы.

Настройки SmartUI сохраняются при обычном обновлении совместимой прошивки.
Предыдущий [SmartUI 0.19](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.19)
сохранён отдельно.

## Что ещё важно знать

- **USB-кабель и режим USB-компаньона — разные вещи.** Для чтения PIN и настройки
  по кабелю в режиме Bluetooth переключать ноду на USB-компаньон не требуется.
  Выбор режима в Helper выбирает протокол связи с нодой, а не переключает саму ноду.
- **«Консоль» не отвечает, а «USB-компаньон» подключается?** Нода уже работает
  USB-компаньоном, текстовая консоль в этом режиме выключена. Продолжайте в
  «Настройки (USB-компаньон)»: там доступны настройки и «Показать PIN».
  Этот тайм-аут не требует перепрошивки или сброса. Для подключения телефона
  отдельно нажмите Bluetooth во вкладке «Подключение» и подтвердите смену.
- **Helper — программа для компьютера.** Его HTML не является прошивкой и не
  загружается во флешер. Реальная работа Helper с USB на телефоне не заявлена;
  мобильная раскладка сама по себе не означает такую поддержку.
- **Экранный и headless UF2 — разные профили.** Выбирайте файл под наличие дисплея
  и распайку. Переход на headless не сбрасывает прежний PIN и выбранный транспорт.
- **Смена PIN применяется после перезагрузки.** До неё `get pin` показывает
  прежний действующий код. `set pin 0` не отключает PIN: при следующем запуске
  headless использует `123456`, экранный профиль с запущенным драйвером создаёт
  случайный код. При обратном переходе с чистого headless на OLED код тоже может
  стать случайным, если отдельный PIN ранее не сохранялся.
- **Кнопка в Helper не доказывает наличие детали.** Зуммер, GPS, вибромотор и
  внешний LED должны быть установлены и подключены к разрешённым выводам.
  Для звука нужны сохранённые настройки и выключенная общая тишина.
- **ADC зависит от конкретной сборки.** Коэффициент не определяется по имени
  FakeTec V4. На ProMicro USB может искажать измерение АКБ; следуйте процедуре
  Helper с замером мультиметром, не подбирайте коэффициент по одному USB-показанию.
- **Изменение поля ещё не сохраняет настройку.** Нажмите «Сохранить» и дождитесь
  подтверждения с чтением обратно. Обрыв связи означает, что результат нужно
  проверить после переподключения.
- **Wi-Fi есть только у четырёх ESP32-плат этого выпуска.** У ProMicro/FakeTec,
  T096 и T114 его нет. Сохранение сети не включает Wi-Fi автоматически — после
  проверки и сохранения отдельно выберите Wi-Fi во вкладке «Подключение».
  Подключение приложения по TCP идёт на IP ноды и порт `5000`, без BLE PIN;
  отдельного TCP-пароля и TLS нет, поэтому используйте только доверенную сеть.

## Проверки и ограничения

Публикация разрешается после полного CI и отдельного аудита: восемь профилей,
двенадцать образов, проверки хранения и протокола, стека ARM, дисплеев и Helper.
Комплект содержит 20 файлов; `RELEASE-MANIFEST.json` указывает исходный commit
и контрольные суммы. Физические испытания всех плат не заявляются.

SmartUI сохраняет собственный выбор транспорта и защиту управления. CLI через
LoRa на ноде не выполняется; старые API201 и Phone GPS не включены.
[Команды по платам](docs/CLI_BOARD_MATRIX_RU.md) · [Все команды](docs/CONSOLE_COMMANDS_RU.md)
· [Инструкция прошивки](docs/FLASHING_RU.md).
