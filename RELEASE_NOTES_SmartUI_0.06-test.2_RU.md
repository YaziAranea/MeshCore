# SmartUI 0.06-test.2 — настройки стали проще

Небольшое обновление test.1: навели порядок в меню. Функции чата, клавиатура, личные сообщения, быстрые фразы и способы подключения сохранены.

**Это тестовый выпуск для шести плат. Исправление зависаний T096 в него не входит.**

## Что изменилось

1. Убрали раздел **«Избранное»** из настроек и назначение его трёх пунктов. Избранные контакты в приложении это не затрагивает.
2. Убрали **«Отменить изменение»** из раздела «Система».
3. Собрали звук в одном месте: **Настройки → Звук и вибро**. Здесь находятся мелодия, громкость, стиль звука, резонанс, выход звука, тип зуммера и вибрация — только те пункты, которые поддерживает конкретная сборка. Искать их в «Дополнительно» больше не нужно.
4. Обычные **«Назад» и «Отмена» оставили**. Можно выйти из выбора без сохранения. При ошибке записи прежнее значение по-прежнему восстанавливается.
5. При обычном обновлении с 0.06/test.1 настройки не сбрасываются. Формат сохранённых данных не меняли. Убрали только лишние пункты, а не защиту от ошибочного сохранения. Для ESP32 важен выбор `update`, а не `merged` — подробнее ниже.

Чтение выбранного ЛС и ответ его отправителю, фильтр ленты по каналу, девять собственных быстрых фраз, отсрочка напоминания на 15 минут и USB-помощник 1.2. [Инструкция по этим функциям](https://github.com/YaziAranea/MeshCore/blob/smartui-0.06-test.2/docs/TEST_0.06_USER_GUIDE_RU.md).

## Как обновиться без очистки

1. **T096, T114, ProMicro:** скопируйте UF2 своей платы на диск загрузчика. Эти образы не записывают область хранилища; отдельный Erase не нужен.
2. **V3, V4.3, Paper:** для работающей ноды выбирайте `update.bin`, адрес **0x10000**, без Erase. Требуются совместимые загрузчик и таблица разделов.
3. **`merged.bin` — только чистая установка по адресу 0x0. Он перезаписывает ключ ноды, контакты и настройки даже без галочки Erase.** Сохраните нужные данные заранее.

Файлы разных плат невзаимозаменяемы. [Подробная инструкция](https://github.com/YaziAranea/MeshCore/blob/smartui-0.06-test.2/docs/FLASHING_RU.md).

## Границы проверки

1. Проверяются сборки всех шести плат, переходы меню, сохранение/отмена и разметка с реальными метриками шрифтов. Это программные проверки, не длительный тест на каждой физической плате.
2. Сообщение о зависаниях T096 остаётся открытым. Причина не установлена; исправление зависаний и изменения библиотек памяти в этот релиз не включены.
3. Ранее сообщавшийся чёрный экран V4.3 после app-only update также не объявляется исправленным.
4. Входящие и история по-прежнему ограничены оперативной памятью и не сохраняются после перезапуска. Постоянных черновиков нет.
5. Wi-Fi companion использует TCP 5000 без отдельного пароля/TLS. Только доверенная локальная сеть, без проброса порта в Интернет.
