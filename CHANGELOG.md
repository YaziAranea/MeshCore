# История изменений

## [Smart UI 0.17](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.17) — 2026-10-09

Дополнение документации в этом же выпуске: [матрица команд по платам](docs/CLI_BOARD_MATRIX_RU.md),
проверка `caps`/`schema`, условия GPIO/вибрации/GPS/дисплея и точное назначение FEM.
Матрица включена в Helper ZIP и Developer Kit; логика прошивки не менялась.

1. Добавлены понятные `sound`, `mute`, `night_quiet`, `sound preview`, `test`,
   `get/set connection` и текстовые `reply get/set/reset`. Фразы не требуют HEX;
   старые машинные команды сохранены. Возможности объявляются через `control=1`.
2. Удалены страницы `help` локального companion CLI. Справочник вынесен в
   документацию; список мелодий отвечает компактно, названия читаются по номеру.
3. Ночная тишина использует существующие настройки и утренний сброс, проверяет
   часы, сохраняется с откатом и не присваивает себе ручной mute. Формат prefs
   не меняется. Сервисный `settings` получил рабочие hooks мелодий и мостового звука.
4. Python/JS SDK и Helper обновлены вместе с контрактом команд. Новые команды
   требуют `control=1`; UTF-8, длина, readonly и сопоставление ответов проверяются.
   Переключение подключения запускается только после постановки ответа в очередь.
5. USB Helper 2.4 и Developer Kit 0.17. Семь плат, одиннадцать образов, отдельный
   выпуск; 0.16 сохранён. Host-тесты, ARM-проверки и сборки не заменяют аппаратные
   испытания. [Описание и выбор файла](RELEASE_NOTES_SmartUI_0.17_RU.md).

## [Smart UI 0.16](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.16) — 2026-10-08

Helper 2.3 показывает мостовой звук без раскрытия расширенных настроек.
Добавлена сводка сохранённых моста, вывода звука и громкости. Обновление звука
перечитывает мост; недоступность и ошибки больше не подменяются выключенным
состоянием или ложным «Прочитано». Код прошивки этим исправлением не меняется.

Следующее обновление того же выпуска: Helper 2.2 заменяет длинную страницу
семью вкладками в сине-серой теме. Хеш вынесен в видимый блок, пины открыты
во вкладке звука, быстрые фразы свёрнуты. Добавлены явное чтение звука/пинов
и отдельное прослушивание сохранённой мелодии: `settings sound preview` /
`ui sound preview`, обнаружение через `caps sound_preview`. Прослушивание
не сохраняет настройки, обходит только маску уведомлений и `sound_quiet`,
но не общую тишину. Старые сборки получают подсказку об обновлении без Erase.

Обновление того же выпуска: Helper 2.1 исправляет инверсию подписи `sound_quiet`,
поясняет состояние перед тестом, предупреждает о несохранённых полях, добавляет
выбор хеша 1/2/3 байта с проверкой остальных радиопараметров. Фразы свёрнуты,
редкие настройки скрыты под расширенным видом. T114 больше не предлагает
несуществующие GPIO 0/1; ProMicro сохраняет свои допустимые 0/1.

1. Локальный CLI отделён от тяжёлого обработчика обычных companion-команд: убран лишний вложенный буфер 1 КБ на nRF52. Сокращены адаптеры настроек; добавлены проверки полного маршрута ADC и ARM-стека. Аппаратное воспроизведение зависания T114 не заявляется.
2. Расширены пользовательские настройки CLI: уведомления, пины света/звука/вибро, стиль и резонанс звука, экран, GPS. Поддержка, диапазоны и разрешённые пины сообщаются самой платой. Сохранение общее с экранным меню, с откатом при отказе.
3. USB Helper 2.0: сгруппированные расширенные настройки, явный результат у поля, чтение обратно, имя ноды, мощность TX, быстрые фразы в обоих режимах подключения. Старые прошивки сохраняют поддержанный набор.
4. Подробная русская справка кастомного CLI и описание схемы настроек для приложений. База MeshCore 1.17.1 сохранена; приватная ретрансляция, удалённое выполнение CLI и архивный API201 не включались.
5. Новый публичный выпуск для семи плат; 0.15 остаётся отдельным для отката.

Все заметные изменения этого проекта документируются здесь. Стабильная линия `v1.0.0` основана на PS16; `v2.0.0-rc1` переносит тот же пользовательский интерфейс на PS17.

## Smart UI 0.15 — 2026-10-07

1. Расширенная локальная консоль: короткие get/set для вибро, громкости, мелодий, FEM, ADC, LED, GPS, AGC и автоанонса. Все изменения через существующие проверки и сохранение меню.
2. Встроенная тематическая `help`, читаемые названия мелодий и полная русская справка `docs/CONSOLE_COMMANDS_RU.md`. Один ответ ограничен размером companion-кадра; нет скрытой выдачи нескольких сообщений вместо ответа.
3. Helper 1.9 и SDK распознают `console=1`, сохраняют совместимость прежних `ui`-команд; помощник допускает `get tx`/`set tx` и показывает разрешённые результаты без раскрытия секретов.
4. Изменение мощности TX отклоняется при занятом радио, до записи настроек. Проверки ADC, запрет записи при ошибках хранилища и аппаратные ограничения сохранены.

### Перенос CLI, включённый в 0.15

1. Перенесён PR #4 с командами оригинального MeshCore на локальном CMD66 рядом с существующими `ui …`. Изменения ADC из 0.14 сохранены. Companion-протокол 14 передаёт текст типа 3 приложению, но не выполняет удалённые команды по LoRa.
2. Исправлены обход `readonly`/`busy` командами перезапуска и выключения, округление процентов и непостоянный после перезапуска `dutycycle`. Для текущего диапазона `airtime_factor` 0–9 принимается `dutycycle` 10–100%; меньшие значения явно отклоняются.
3. Python/JavaScript-клиенты обнаруживают новые команды по `meshcore=1`, поддерживают UTF-8 имена и распознают разные формы ошибок оригинального CLI. Нет произвольного выполнения команд, автоматического повтора записи или объявления разрыва соединения успешным перезапуском.
4. Выпускается отдельным 0.15; BIN/UF2 и страница 0.14 не заменяются. Аппаратные испытания не заявляются.

## [Smart UI 0.14](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.14) — 2026-10-07

Обновление того же релиза: прямой ввод проверенного ADC-коэффициента через локальный CLI и USB Helper 1.8; отдельное обнаружение возможности без изменения legacy caps. Сохранение транзакционное, с прежним диапазоном и чтением обратно; успешная запись закрывает сервисное окно. Два способа калибровки и сообщения непосредственно возле ADC-формы. Номер 0.14 сохранён; нужны обновлённые прошивка и помощник.

1. Явное сервисное окно калибровки ADC: максимум 120 секунд, только локальный USB и достоверно подтверждённое USB-питание. На nRF52 ошибка чтения USB-статуса больше не может считаться подтверждением для этого режима; обычная политика питания не меняется.
2. Окно не хранится во flash, не продлевается повторным стартом, прекращается при потере питания/сеанса, успешном сохранении/сбросе ADC, ручной остановке или тайм-ауте. Обычные пороги 3,2/2,7 В сохранены.
3. USB Helper 1.8: подтверждение запуска, статус и оставшееся время, понятные шаги ProMicro с опорным замером до USB. Старые прошивки и платы без надёжного детектора сохраняют обычную калибровку.
4. Семь плат, включая R8 OLED, одиннадцать образов, 19 файлов. 0.13 сохранена отдельно. [Инструкция и границы проверки](RELEASE_NOTES_SmartUI_0.14_RU.md).

## [Smart UI 0.13](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.13) — 2026-10-07

Исправление в этом же выпуске: корректные городские пресеты могли отклоняться на ProMicro из-за округления полосы при `-Ofast`. Канонические значения полосы теперь общие для помощника и штатного companion-протокола; старые профили с погрешностью в пределах двух шагов float восстанавливаются без erase. Добавлены проверки с реальной настройкой оптимизации nRF52. Helper остаётся 1.6.

1. USB Helper 1.6: новый интерфейс, поиск городского пресета MeshCoreTel и подтверждаемое применение полного набора радиопараметров. Офлайн-каталог с датой источника; автоматической смены частоты нет.
2. Чтение и настройка автоанонса с теми же интервалами, что в меню ноды: выключен, 15/30/60/120/180 минут.
3. Общие команды радио и автоанонса для Companion CLI и сервисной USB-консоли. Проверки диапазонов, сохранения и повторного чтения; мощность и ретрансляция сохраняются.
4. Добавлена Heltec V4 R8 OLED FEM ON: отдельный профиль PSRAM/GPIO, ADC, LED, GPS, питание FEM, пара merged/update и распознавание в помощнике. Обычная V4.3 R2 сохранена отдельно; TFT R8 не включён. Физическое испытание R8 не заявляется.
5. Семь плат, одиннадцать образов и 19 файлов публичного выпуска; база 1.17.1/protocol 13 и архив API 0.11 сохранены. [Инструкция и границы проверки](RELEASE_NOTES_SmartUI_0.13_RU.md).

## [Smart UI 0.09](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.09) — 2026-10-06

1. В `Настройки → Система` добавлен `AGC-сброс`: по умолчанию `ВЫКЛ`, долгое нажатие переключает и сохраняет выбор. Пункт скрыт без поддержки радиомодуля.
2. Включённая функция планирует перекалибровку приёмника с интервалом 60 секунд и откладывает её при активности радио или ожидании ответа. Нода не перезапускается, данные не стираются; короткое окно без приёма во время операции остаётся.
3. Добавлены программные проверки таймера, сохранения, поэтапной работы с радио, ошибок и размещения пункта на экранах. Физические испытания AGC не проводились; это пробная профилактика, не доказанное исправление зависаний или связи.
4. Исправлен выявленный по коду сценарий сохранения настроек при нехватке места: одна повторная попытка может освободить только старую копию `prefs.json.bak`, после проверки чтения и синтаксиса основного файла и наличия необходимых разделов. Новый файл проверяется до замены; форматирование, удаление контактов и ключей не выполняются. Это не гарантия восстановления повреждённой файловой системы.
5. При ошибке сохранения AGC выводится код неудачного этапа, а не предположение о причине. Обновление UF2 и включение AGC не требуют Erase.
6. Шесть плат, USB-помощник 1.3 и настройки через USB из 0.08 сохранены. [Как включить, выбрать файл и обновиться](RELEASE_NOTES_SmartUI_0.09_RU.md).

## [SmartUI V5](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-v5) — 2026-09-19

- Исправление на той же странице V5: nRF52 flash-cache больше не обходит
  `LED платы: ВЫКЛ`. Вызовы `ledOn` для встроенного LED проходят через
  общий выключатель на T114/T096/ProMicro; операции записи данных не меняются.
  Первоначальный V5 исправлял только TX/UI и не закрывал этот источник мигания.
  UF2 нужно скачать заново; внутренний маркер исправленных сборок — `LED2`.

- `LED платы: ВЫКЛ` стал общим запретом для встроенных LED: статус,
  LoRa TX и уведомление на том же штатном GPIO не включают их повторно.
- Встроенный GPIO уведомления подчиняется общему выключателю; отдельный
  внешний LED на другом GPIO сохраняет собственные настройки.
- LoRa TX не считается непрочитанным сообщением: радио продолжает работать,

- PowerShell-рецепт checksum-манифестов теперь пишет переносы LF, совместимые с `sha256sum -c` в Linux/macOS.
- Если stock PS17 уже создал `prefs.json` без секции `smart_ui`, настройки SmartUI один раз и только один раз дочитываются из сохранённого PS16 `/new_prefs`.
- BLE-синхронизация времени принимает корректное время телефона назад и вперёд в безопасном диапазоне 2024–2040. При исправлении будущего RTC назад также перестраивается внутренний unique-timestamp floor, поэтому сообщения не продолжают уходить с датой из старого будущего.
- Wireless Paper больше не показывает аппаратно невозможные режимы оповещения; три быстрых слота получают рабочий capability-aware fallback вместо дублированного `Оповещения`.
- Предпросмотр коэффициента ADC больше не меняет сохранённую настройку до подтверждения; отмена возвращает рабочее значение.
- T114 и Wireless Paper получили реально изменяемый коэффициент измерения АКБ; на Wireless Paper добавлена задержка стабилизации ADC.

### Добавлено

- Калибровка АКБ/ADC доступна на всех пяти поддерживаемых платах и хранится в `smart_ui.adc`.
- Heltec V4.3 OLED FEM ON: полный SmartUI, аппаратный GPS, управление LNA/FEM, экранная клавиатура и правильные ESP32-S3 BIN-файлы.
- Heltec Wireless Paper: точный 250×122 e-paper UI, кириллица, пять компактных font-profile, защита общей линии GPIO45/VEXT и два профиля:
  - `WOOD` — рекомендуемый, без дорогой для e-paper экранной клавиатуры;
  - `FULL` — клавиатура и target picker, с периодическим полным обновлением против ghosting.
- CI отдельно собирает и проверяет три nRF52 UF2 и три пары ESP32-S3 `freshInstall-merged.bin` / `update.bin`.

### Ограничения

- Это предварительный GitHub Release, а не новый стабильный выпуск. Компиляция и симуляция не заменяют проверку V4.3 и Wireless Paper на реальном железе.
- Wireless Paper V1.0 не заявлен; профиль рассчитан на ревизии с поддерживаемым определением BUSY polarity.
- На V4.3 и Wireless Paper физического зуммера нет: прошивка не назначает выдуманный tone GPIO.

## [1.0.0] — 2026-08-21

### Добавлено

- Единый русскоязычный Smart UI для T096 FEM ON, T114 и ProMicro RA62.
- Экранная клавиатура в меню быстрых ответов.
- Выбор адресата перед отправкой: известный чат или companion-контакт.
- Фильтрация ретрансляторов из списка контактов.
- Sender-centric окно непрочитанных личных сообщений.
- Отдельные списки выбора шрифта, темы и общей мелодии.
- Индикаторы прокрутки, полнострочное выделение и UTF-8-safe сокращение через `...`.
- Аппаратный GPS UI для T096/T114 с состояниями `GPS ON/OFF`.
- Ночной запрос тишины в 23:30 до 07:30.
- Публичная русская документация по платам, управлению, прошивке, сборке, SHA-256, безопасности и экранам.

### Изменено

- Одна общая мелодия заменяет раздельные мелодии ЛС, системы и упоминаний.
- Серия важного уведомления ограничена двумя проигрываниями.
- Настройки сгруппированы; низкоуровневые GPIO и тесты перенесены в `Дополнительно`.
- Длинные строки в многорядных меню статически сокращаются вместо одновременной бегущей строки.
- BLE PIN-страница T096 исчезает после подключения.
- T114 UI проверяется после реального масштабирования логических 128×64 в физические 240×135.
- T096 клавиатура и target picker используют безопасные role-fonts с реальными bitmap-метриками.

### Исправлено

- Окно непрочитанных больше не показывает всю историю каналов.
- Локальное удаление ЛС и поздняя BLE-синхронизация не списывают следующее сообщение дважды.
- Повторный callback не запускает третье проигрывание важной мелодии.
- Важное сообщение не перекрывается ночным запросом и не теряет управление кнопкой.
- ProMicro выходит из сна по пользовательской кнопке D6/GPIO6 без обязательного Reset.
- Убраны две пустые страницы между чатом и настройками.
- Статусы и пиктограммы не должны перекрывать друг друга на целевых геометриях.

### Удалено или отключено

- Phone GPS, поскольку без отдельного phone-side приложения координаты не поступают.
- Экспорт/импорт настроек и выбор профиля из пользовательского экранного меню.
- Ретрансляторы из списка адресатов `Контакты`.
- FakeTec, Heltec V3/V4 и другие платы из области публичного релиза.

### Проверено

- Три публичных PlatformIO environments `v1.0.0` собрались с `SUCCESS`.
- Статический контракт: `31 PASS / 0 FAIL`.
- Точная framebuffer-симуляция: `455 PASS / 0 FAIL`.
- Проверялись UF2 magic values, блоки, адрес старта и маркеры версии.

### Известные ограничения

- Отдельная физическая проверка именно публичной упаковки `v1.0.0` не заявляется.
- T096 близок к пределу flash; публичная сборка `v1.0.0` занимает 96.7% области приложения.
- Phone GPS не поддерживается.
