# Smart UI 0.19 — исправления после аудита

Выпуск для **семи плат**, с **USB Helper 2.6** и **Developer Kit 0.19**.
Основное — надёжнее настройка звука, GPIO и экрана. Прежние команды,
настройки и страница BLE PIN сохранены.

## Что исправили — простыми словами

- **Один вывод — одна новая задача.** Раньше меню на nRF52 позволяло назначить
  звук и вибрацию на один GPIO, хотя CLI это запрещал. Теперь проверка общая
  для меню и команд на всех семи платах. Старые назначения сами не меняются.
- **Мостовой звук не переставляет другие выходы.** На T096/T114 его включение
  могло молча передвинуть LED и создать конфликт с вибрацией. Теперь занятая
  пара даёт `pin_conflict`, без изменения настроек. Освободите нужные выводы
  с учётом своей распайки и повторите. Ошибка сохранения тоже не меняет выходы.
- **Смена оформления не обрывает мелодию.** Шрифт, тема и подсветка больше
  не запускают перенастройку GPIO уведомлений.
- **Исправлен сбой дисплея T114 при нехватке памяти.** Убраны повторные выделения
  памяти для каждой строки, добавлена проверка неудачного запуска экрана.
  Также исправлены соседние ошибки буфера в общем драйвере OLED/TFT.
  Это исправления конкретных программных ошибок, а не обещание устранить
  любую аппаратную причину чёрного экрана.
- **Проверка релизной сборки стала строже.** Скрытые локальные настройки сборки
  больше не позволяют выдать изменённую прошивку за сборку из чистого коммита.
- **Helper быстрее сохраняет простые настройки по USB-компаньону.** После
  изменения громкости или оформления он проверяет нужное поле, не перечитывая
  всё устройство. Связанные настройки по-прежнему обновляются целиком.
  Если ответ потерян, успех не показывается и запись сама не повторяется.

При отказе памяти на самом первом запуске дисплея нода продолжает работу
без экрана до перезапуска. Автоматического восстановления экрана в этой
ситуации выпуск не добавляет.

## Где пароль Bluetooth

На **всех семи платах**: с экрана часов сделайте **один переход вперёд** —
откроется **BLE PIN**. Страница доступна и при уже подключённом приложении.
Если экран погас, первое нажатие может только разбудить его.

Если написано «Включите BLE», откройте **Настройки → Система → Подключение → BLE**
и подтвердите смену режима. Затем выберите ноду в приложении и введите шесть
цифр с экрана. Открытие страницы само по себе Bluetooth не включает и PIN не меняет.

## Как обновиться и сохранить данные

1. Скачайте файл **строго для своей платы** из таблицы ниже.
2. **T096, T114, ProMicro:** войдите в UF2-загрузчик двойным Reset и скопируйте
   UF2 на появившийся диск. **Не используйте `FLASH_ERASE`.**
3. **V3, V4.3, V4 R8, Paper:** для работающей SmartUI с совместимой разметкой
   используйте **`-update.bin` по адресу `0x10000` без Erase**.
4. После запуска проверьте версию `0.19`, подключение и свои настройки.
   Для работы с компьютера скачайте новый Helper 2.6; старый HTML сам не обновится.

**`-merged.bin` предназначен для чистой установки по адресу `0x0`.
Он удаляет identity и настройки даже без Erase Flash. Для сохранения данных
используйте update.** Если разметка неизвестна, сначала прочитайте
[инструкцию по прошивке](https://github.com/YaziAranea/MeshCore/blob/smartui-0.19/docs/FLASHING_RU.md).

## Какой файл выбрать

| Плата | Файл |
| --- | --- |
| Heltec T096 FEM ON | `T096_UI_0.19.uf2` |
| Heltec T114 с дисплеем | `T114_UI_0.19.uf2` |
| ProMicro nRF52840 + RA62 + OLED | `ProMicro_RA62_UI_0.19.uf2` |
| Heltec V3 OLED | `Heltec_V3_UI_0.19-update.bin` / `-merged.bin` |
| Heltec V4.3 OLED R2 | `Heltec_V4.3_UI_0.19-update.bin` / `-merged.bin` |
| Heltec V4 R8 OLED | `Heltec_V4_R8_UI_0.19-update.bin` / `-merged.bin` |
| Wireless Paper FULL | `Paper_UI_0.19-update.bin` / `-merged.bin` |

**V4.3 R2 и V4 R8 — разные файлы.** V4 TFT и T114 без дисплея в этот набор не входят.
`SmartUI_0.19_all-boards.zip` содержит полный комплект. Helper — HTML-приложение
для компьютера, его нельзя загружать во флешер. Контрольные суммы и
`RELEASE-MANIFEST.json` входят в выпуск.

## Проверки и совместимость

Публикация разрешена только после полного CI: сборки семи плат, дополнительные
профили без экрана, тесты CLI и сохранения настроек, реальные C++-обработчики
GPIO, проверки памяти ASan/UBSan, браузерные тесты Helper и проверка всех
**11 образов прошивки**. Это программные проверки; физические испытания
каждого экземпляра платы не заявляются.

База — MeshCore **1.17.1**, companion-протокол **14**, локальный CLI **CMD66/RESP29**,
версия контракта **1**. Миграция настроек не требуется. Проверяйте возможности
через `caps`/`schema`, а не по одному номеру версии.
Предыдущий [Smart UI 0.18](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.18)
сохранён отдельно.
