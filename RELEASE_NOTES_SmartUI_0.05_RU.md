# SmartUI 0.05

Одна прошивка для платы, способ подключения выбирается на самой ноде.
Продолжение 0.04; предыдущий выпуск сохранён для отката.

## Обновление 25 сентября: автоматическое подключение

1. Wi-Fi/TCP принимает первое приложение автоматически, без запроса на экране и без пробуждения дисплея. Второй клиент не вытесняет текущего. При настройке сети, CLI rescue и восстановлении хранилища новые клиенты не допускаются.
2. На странице подключения указан `TCP: 5000 авто`; IP остаётся отдельной строкой.
3. Вместо общего «Режим не сохранён» показаны причина, подсказка и код C01–C12. Ошибка не исчезает через секунду: она остаётся на странице подключения до следующей попытки. Защита записи не обходится.
4. Вход в сервисный режим ранним удержанием кнопки теперь отмечается на экране. Если причина C02: перезапустите ноду без удержания кнопки, подождите 10 секунд и повторите выбор. Это не стирает данные. Сообщение участника о первопричине отказа сохранения пока не подтверждено; новые пояснения не выдаются за ремонт физической памяти.

**Изменение доступа:** отдельного пароля TCP и TLS нет. Любой имеющий сетевой доступ к ноде сможет подключиться автоматически с правами companion-приложения. Использовать только в доверенной локальной сети; не пробрасывать порт 5000 в Интернет.

Отдельный отказ запуска app-only `update` у участника не воспроизведён и не объявляется исправленным этим обновлением. Формат и адрес записи не менялись. При повторе нужен загрузочный лог; не стирайте память ради диагностики.

## Обновление 0.05: запуск Wi-Fi и USB-помощник

1. Исправлен преждевременный запуск TCP-сервера: он больше не открывает сокет до запуска Wi-Fi и получения соединения. Ошибка могла вызвать аварийную перезагрузку при выборе Wi-Fi, в том числе при старте с сохранённым режимом. Сообщение о таком поведении получено для V4.3; исправление общее для ESP32.
2. Если проверенная новая сеть пропадает до нажатия «Сохранить», нода больше не подменяет её подключением к прежней сети. Сохранение явно запускает новую сеть.
3. Добавлен `SmartUI_USB_Helper_1.0.zip`: распакуйте и откройте HTML в Chrome/Edge на компьютере. Кнопки проверки/сохранения Wi-Fi, статуса и выбора подключения заменяют ручной ввод команд. Установка и Интернет не нужны; USB-доступ выдаётся пользователем.
4. Пароль не попадает в журнал помощника. Проверка сети и сохранение разделены. После переключения на USB-компаньон помощник освобождает порт; результат надо проверить на экране ноды.

[Инструкция USB-помощника](https://github.com/YaziAranea/MeshCore/blob/smartui-0.05/tools/usb-helper/README_RU.md).

**Исправлены код и проверяемый сценарий запуска; физическое повторное испытание V4.3 не заявляется.** Если чёрный экран появляется сразу после прошивки, ещё до выбора Wi-Fi, нужен загрузочный лог: этот симптом сам по себе не доказывает ту же причину.

Для установки исправления повторно скачайте файл: имена и страница релиза сохранены, SHA256 обновлены. `update` сохраняет данные только при целой разметке и загрузчике. В веб-флешере обязательно выключите `Erase device`/`Erase Flash` для `update`; очистка с app-only файлом удалит загрузчик. Не переходите на `merged` ради проверки: он удаляет данные ноды.

## Что добавлено

1. `Настройки → Подключение`: Bluetooth, USB Serial или Wi-Fi — по возможностям платы.
2. На V3, V4.3 и Wireless Paper доступны все три способа. На T096, T114 и ProMicro — Bluetooth и USB Serial; встроенного Wi-Fi у этих nRF52840-плат нет.
3. Выбор сохраняется. Одновременно работает один канал приложения: ответы и состояние разных подключений не смешиваются.
4. В режимах Bluetooth/Wi-Fi USB работает как сервисная консоль. В режиме USB тот же порт передаёт бинарный протокол MeshCore и не смешивается с текстом консоли.
5. Wi-Fi настраивается командой `wifi setup`: имя сети, пароль, пробное подключение и отдельное подтверждение сохранения. Перекомпиляция и ввод пароля кнопкой ноды не нужны.
6. Первое TCP-подключение принимается автоматически. Отдельного TCP-пароля и TLS нет; используйте доверенную локальную сеть, не открывайте порт в Интернет.
7. Неудачная попытка настройки не заменяет сохранённые реквизиты. Нет роутера — LoRa, экран и кнопки продолжают обслуживаться; вернуться к Bluetooth можно через меню.
8. USB больше не считается подключённым только потому, что этот интерфейс существует. Соединение определяется по обмену с приложением; доступное аппаратное определение отключения также учитывается.
9. Переключение очищает только состояние соединения. Identity, контакты, настройки радио и очередь непрочитанных сообщений сохраняются.

[Инструкция по подключениям и консоли](https://github.com/YaziAranea/MeshCore/blob/smartui-0.05/docs/CONNECTIONS_0.05_RU.md).

## Ограничения

- Это один активный клиент, не одновременная работа телефона и нескольких компьютеров.
- Для Wi-Fi нужен клиент MeshCore с поддержкой TCP/IP. TCP-сервер не является браузерным веб-чатом.
- USB Serial означает USB-разъём/COM-порт платы, не отдельный UART на контактах GPS.
- Wi-Fi может увеличить потребление. Неиспользуемый Wi-Fi выключается; замеры автономности на физических платах не заявляются.
- Пароль не выводится прошивкой в консоль, но терминал с включённым локальным эхом может показать ввод. Отключите Local Echo и запись сеанса перед настройкой.
- Реквизиты хранятся в локальной flash-памяти. Защита от физического чтения flash и шифрование реквизитов этим выпуском не заявляются.
- Сборки, хост-тесты и симуляции не заменяют испытаний конкретной платы, USB-драйвера, роутера и приложения.
