# MeshCore SmartUI PS17 v2.1.0-beta.1

Публичный предварительный выпуск от 2026-09-01 для Heltec T096 FEM ON,
Heltec T114, ProMicro RA62, Heltec V4.3 OLED FEM ON и Heltec Wireless Paper.
Это одна общая beta-страница: повторный запуск публикации того же тега обновляет
файлы на ней, а не создаёт дубликат Release.

[Скачать файлы Release](https://github.com/YaziAranea/MeshCore/releases/tag/v2.1.0-beta.1)
· [прошивка](docs/FLASHING_RU.md) · [проверка SHA-256](docs/VERIFY_RU.md)

> Beta означает, что код прошёл сборку, native-тесты и framebuffer-симуляции,
> но полный цикл физической проверки каждой платы не заявляется. Для быстрого
> отката сохранён [v2.1.0-dev.2](https://github.com/YaziAranea/MeshCore/releases/tag/v2.1.0-dev.2).

## Главное

- Companion-команды сначала проверяются по длине и форме. Закрыты чтение за
  границей короткого кадра, повторное использование хвоста старого кадра и
  переполнение при коротком сообщении канала.
- Адресат экранной клавиатуры и ожидаемый ACK теперь сохраняются по неизменяемому
  номеру канала или public key, а не по позиции в меняющемся списке и не по
  указателю на перемещаемую запись контакта.
- `prefs`, контакты, каналы и identity записываются через проверенный временный
  файл с резервным поколением. Незавершённая запись больше не должна уничтожать
  последнюю исправную конфигурацию.
- Повреждение всех поколений identity больше не маскируется тихим созданием
  нового адреса ноды. Первый чистый запуск и повреждение хранилища различаются.
- Защита АКБ больше не считает напряжение ниже 2,5 В «невалидным». Аварийный
  контроль использует отдельные сырые измерения и не ждёт медленное сглаживание
  числа на экране. Основной порог остаётся 3,2 В, резервный при отключённой
  защите — 2,7 В.
- Калибровка ADC ограничена безопасным диапазоном конкретной платы, имеет
  восстановление заводского множителя двойным щелчком вне режима правки и
  защищена от NaN/переполнения. Неудачная запись не оставляет preview рабочим.
- RTC различает доверенное время телефона/GPS/аппаратных часов и приблизительное
  время из контактов. Приближение не перезаписывает исправные часы и не запускает
  ночной режим. Старый искусственный seed больше не выдаётся за синхронизацию.
- Добавлена настройка часового пояса `UTC−12:00…UTC+14:00` с шагом 30 минут;
  листание ничего не пишет, сохраняется только подтверждённое значение. Default
  `UTC+06:00` сохраняет прежнее поведение.
- Таймеры интерфейса и проверки АКБ используют сравнение, корректное при
  переполнении `millis()`. Опрос состояния радиоканала ограничен одним разом в
  100 мс и не приписывает весь сон занятому эфиру.
- Компактный аптайм `U 12m` / `U 7h` / `U 3d` убран из меню и показывается
  только на экране часов. Позиция считается по реальной ширине текущего шрифта;
  при нехватке места используется более короткая форма, а не наложение значков.
- Serial/BLE/Ethernet transport полностью отбрасывает слишком длинный кадр или
  строку до следующей границы сообщения — усечённый префикс больше не исполняется.
- Команды изменения настроек возвращают ошибку записи вместо ложного `OK`;
  критичные radio/channel/ADC/часовой пояс откатываются при неудачной фиксации,
  а перезагрузка не теряет отложенную запись контактов.
- Снимок сети для распознавания упоминаний вынесен из стека loop-задачи; поиск
  не повторяет одни и те же вычисления.
- ESP32 больше не форматирует SPIFFS автоматически при ошибке монтирования.
  Миграция во вторичное хранилище удаляет источник только после проверки размера
  и CRC копии.
- Зависимости, влияющие на релизные сборки, закреплены точными версиями/commit.

## Какой файл скачать

### nRF52840 — UF2

| Плата | Файл |
|---|---|
| Heltec T096 FEM ON | `T096_FEM_SmartUI_2.1.0-beta.1.uf2` |
| Heltec T114 с TFT | `T114_SmartUI_2.1.0-beta.1.uf2` |
| ProMicro nRF52840 + Heltec RA62 | `ProMicro_RA62_SmartUI_2.1.0-beta.1.uf2` |

UF2 копируется на загрузочный USB-диск платы после быстрого двойного Reset.

### ESP32-S3 — BIN

| Плата/профиль | Чистая установка, адрес `0x00000` | Обновление, адрес `0x10000` |
|---|---|---|
| Heltec V4.3 OLED FEM ON | `Heltec_V4.3_OLED_FEMON_SmartUI_2.1.0-beta.1-freshInstall-merged.bin` | `Heltec_V4.3_OLED_FEMON_SmartUI_2.1.0-beta.1-update.bin` |
| Wireless Paper WOOD | `Heltec_Wireless_Paper_WOOD_SmartUI_2.1.0-beta.1-freshInstall-merged.bin` | `Heltec_Wireless_Paper_WOOD_SmartUI_2.1.0-beta.1-update.bin` |
| Wireless Paper FULL | `Heltec_Wireless_Paper_FULL_SmartUI_2.1.0-beta.1-freshInstall-merged.bin` | `Heltec_Wireless_Paper_FULL_SmartUI_2.1.0-beta.1-update.bin` |

`freshInstall-merged.bin` содержит загрузчик, partition table и приложение.
`update.bin` — только приложение. Не меняйте файлы или адреса местами.

Весь набор также находится в
`MeshCore_SmartUI_2.1.0-beta.1_all-five-boards.zip`. В Release публикуются
`SHA256SUMS.txt`, `SHA256SUMS-ESP32.txt` и машинный `RELEASE-MANIFEST.json`.

## Обновление и откат

- Обычное обновление сохраняет совместимые настройки и identity, но перед beta
  всё равно сделайте защищённую резервную копию идентичности.
- После первого запуска откройте `Система → Часовой пояс` и проверьте местное
  время. Пока RTC не получил доверенную синхронизацию, часы/ночной запрос не
  притворяются корректными.
- Проверьте `Дополнительно → Калибр. АКБ`. Если раньше был сохранён экстремальный
  коэффициент, beta вернёт безопасное значение; заводское значение можно
  восстановить из экрана калибровки.
- Для отката используйте файлы своей платы из `v2.1.0-dev.2`. Возврат на stock
  может удалить секцию `smart_ui` при следующем сохранении настроек.

## Проверка выпуска

Локальная финальная проверка того же исходного дерева:

- native policy/protocol/storage: `140/140`;
- KISS modem: `8/8`; raw serial overflow: `2/2`;
- общий статический контракт: `102/102`;
- точная UI-симуляция: core `470/470`, V4.3/ProMicro `175/175`,
  Wireless Paper `525/525`, документационные clock-layout `243/243`;
- настоящий host-renderer SSD1306: `150/150`; confirmed-choice sweep: `2192/2192`.

| Конфигурация | RAM | Flash приложения |
|---|---:|---:|
| T096 FEM ON | 151172 / 235520 (64,2%) | 565604 / 712704 (79,4%) |
| T114 | 152596 / 235520 (64,8%) | 568656 / 712704 (79,8%) |
| ProMicro RA62 | 149076 / 235520 (63,3%) | 533336 / 712704 (74,8%) |
| V4.3 OLED FEM ON | 177444 / 2097152 (8,5%) | 1517869 / 6553600 (23,2%) |
| Wireless Paper WOOD | 175360 / 327680 (53,5%) | 1311637 / 3342336 (39,2%) |
| Wireless Paper FULL | 175368 / 327680 (53,5%) | 1317129 / 3342336 (39,4%) |

Все три UF2 проверены по структуре, family ID и встроенному маркеру версии. Для
каждой ESP32-S3-сборки проверены заголовки обеих BIN и точное совпадение
`update.bin` с app-срезом `freshInstall-merged.bin` по адресу `0x10000`.
Полные SHA-256 находятся в `SHA256SUMS.txt`, `SHA256SUMS-ESP32.txt` и
`RELEASE-MANIFEST.json` на странице Release. Публикация тега дополнительно
проходит единый [GitHub Actions gate](https://github.com/YaziAranea/MeshCore/actions/workflows/smartui-ci.yml).

Симуляция учитывает реальные bitmap-метрики/xAdvance T096, физическое
масштабирование T114 128×64 → 240×135, встроенные OLED glyph-таблицы и реальную
геометрию Wireless Paper 250×122. Это не фотография и не электрическое испытание.

## Известные ограничения

- Phone GPS выключен: без отдельного phone-side приложения нода не может сама
  запросить координаты телефона по BLE.
- WOOD — рекомендуемый экономичный профиль Wireless Paper без экранной
  клавиатуры; клавиатура есть в FULL.
- В профилях V4.3 и Wireless Paper не назначен выдуманный GPIO зуммера, поскольку
  физический зуммер для этих целей не заявлен.
- Программная защита АКБ не заменяет исправную BMS, проверенный делитель ADC и
  аппаратные испытания конкретного экземпляра.
- FakeTec/HT-RA62 и дополнительные compatibility-цели не входят в комплект
  файлов этого Release.
