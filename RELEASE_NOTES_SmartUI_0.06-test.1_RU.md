# SmartUI 0.06-test.1 — отдельный тестовый выпуск

Это SmartUI 0.06 с исправлениями повторного аудита и новыми возможностями общения без телефона. **Версия для добровольного тестирования, не замена стабильной 0.06.**

[Стабильная 0.06](https://github.com/YaziAranea/MeshCore/releases/tag/smartui-0.06) остаётся доступной и сохраняет отметку Latest. Этот выпуск опубликован отдельно с `test` в названии.

## Что стало удобнее

1. **Личные сообщения можно открыть и прочитать на ноде.** Выберите сообщение во входящих. Доступны ответ именно этому человеку, отметка выбранного сообщения прочитанным и возврат к списку. Одинаковые имена не путают адресатов: используется ключ контакта.
2. **Ленту можно отфильтровать по каналу.** В действиях чата выберите все каналы или один нужный. Изменение канала в приложении не переносит старые сообщения на новый ключ.
3. **Быстрые фразы теперь ваши.** USB-помощник 1.2 позволяет менять девять фраз без пересборки прошивки. До 64 байт UTF-8 на фразу; пустое значение возвращает стандартный текст. Сохранение отдельное и явное.
4. **Напоминание можно отложить на 15 минут.** Выбранное ЛС остаётся непрочитанным. Это не общий беззвучный режим: новые сообщения продолжают оповещать.
5. **Помощник проверяет выбранный файл прошивки.** BIN/UF2 и `RELEASE-MANIFEST.json` проверяются локально: плата, тип файла, версия, контрольная сумма. Помощник сам ничего не прошивает и никуда не отправляет файл.

## Что исправлено

1. При восстановлении Wi-Fi-настроек последняя исправная копия сохраняется до проверки новой.
2. Открытие USB-помощника больше не должно переподключать уже работающий Wi-Fi без причины.
3. Согласованы сообщения об ошибках и повтор безопасного удаления Wi-Fi-настроек. Ошибка восстановления в USB-режиме не закрывает одновременно все способы обслуживания.
4. Убрана ошибка перерисовки после примерно 25 суток работы.
5. Кэш высоты чата обновляется по изменению истории: длинный текст не должен терять конец из-за старого предела прокрутки.
6. Неподдерживаемые радиопараметры отклоняются. При ошибке применения или сохранения возвращается прежняя конфигурация; `OK` не выдаётся за отказ радиочипа.
7. Слишком длинное сообщение канала отклоняется вместо молчаливого обрезания, в том числе посреди русской буквы. Экранная клавиатура сохраняет прежний безопасный размер.
8. При достоверно обнаруженном внешнем питании обычный порог АКБ не мешает работе на зарядке, но аварийный порог 2.7 V сохраняется. Без подтверждённого внешнего питания правила 3.2 V / 2.7 V не меняются.
9. Уменьшен расход стека при сохранении настроек. Это особенно важно для T096, T114 и ProMicro после добавления пользовательских фраз: служебные копии настроек больше не должны переполнять маленький стек меню. При нехватке памяти изменение отклоняется, а не сохраняется частично.

## Ограничения тестовой версии

1. Входящие и история находятся в ограниченном RAM-буфере. После перезагрузки они не сохраняются; вытесненное сообщение нельзя восстановить этим экраном. Постоянных черновиков нет.
2. Фильтр каналов не увеличивает память и не гарантирует отдельный архив каждого канала.
3. Отсрочка напоминания действует, пока запись сохраняется в памяти. Перезагрузка сбрасывает временные отсрочки. Общие беззвучный и ночной режимы продолжают действовать.
4. Проверка файла не доказывает исправность платы или совместимость уже установленного bootloader/partition table. Хеш из manifest подтверждает совпадение, а не подлинность сам по себе.
5. Причина ранее сообщавшегося чёрного экрана при app-only update на V4.3 без загрузочного лога не установлена. Этот релиз не объявляет её исправленной.
6. У V4.3 с native USB CDC автоматический light sleep остаётся отключённым, как в текущем upstream. Фактическую экономию энергии нужно измерять на платах.
7. Wi-Fi companion — TCP **5000**, автоматическое подключение первого клиента в доверенной локальной сети. Отдельного пароля/TLS нет. Не открывайте порт в Интернет.

Все платы одним архивом: `SmartUI_0.06-test.1_all-boards.zip`.

USB-помощник: `SmartUI_USB_Helper_1.2.html` либо `SmartUI_USB_Helper_1.2.zip`. Проверка прошивки доступна без подключения ноды; для сравнения с обнаруженной платой подключите сервисную консоль. Новые быстрые фразы требуют именно тестовую прошивку; обычные функции подключения совместимы с 0.05/0.06.

## Важно перед прошивкой ESP32

1. `update.bin` — только приложение, адрес **0x10000**, **без Erase**, при совместимых существующих bootloader и таблице разделов.
2. `merged.bin` — чистая установка, адрес **0x0**. **Перезаписывает ключ ноды, контакты и настройки даже без галочки Erase.**
3. Перед изменением прошивки сохраните нужные данные. Файлы разных плат невзаимозаменяемы.

[Как пользоваться новыми функциями](https://github.com/YaziAranea/MeshCore/blob/smartui-0.06-test.1/docs/TEST_0.06_USER_GUIDE_RU.md).

Проверки сборки и симуляции не являются аппаратным тестированием всех плат. После установки особенно полезны отзывы о ЛС/ответе, новом ЛС во время отсрочки и отображении длинного русского текста; указывайте плату и полное имя файла.
